# Lumi Design System Brief

## Product
Lumi is a focused learning workspace for notes, folders, search, linked canvases, a knowledge graph, Lumi Coach, and settings. The current app is a Flutter Material 3 web app. Drafts should represent the existing desktop study workspace and show the same screen in light and dark themes.

## Direction
Use the approved **warm paper and sage** direction: a quiet, reading-oriented workspace; soft warm paper background; warm white reading surfaces; deep ink text; muted sage for primary actions and selected states; restrained terracotta for occasional emphasis. Dark mode is a coordinated warm, low-glare version with the same hierarchy and sage accent. Keep the UI calm and focused for long study sessions.

## Palette anchors
- Light canvas `#F4F1E8`, surface `#FFFCF5`, text `#292D28`.
- On web startup, rotate the secondary accent in this order: sage green, blue, light orange, and maroon. The first launch uses sage green; keep the chosen accent consistent across the UI until the next startup. Persist the light/dark theme independently of this cycle.
- Build accessible coordinated dark equivalents for each accent; do not invert the light palette mechanically.
- Use clear muted secondary text and fine warm borders.

## Typography and shape
Use DM Sans for interface text and restrained Lora for editorial reading accents. Use 4/8px spacing, modest control and card radii, fine borders, and subtle depth.

## Product constraints
Preserve the current Notes, Search, Canvas, Graph, Coach, and Settings workflows and their visible actions. Do not add progress tracking, timers, gamification, or motivational claims. Avoid loud gradients, heavy shadows, large decorative artwork, or continuous motion. Keep sidebar, reading/editor area, contextual actions, responsive Coach, and both appearance modes legible.

## Existing brand assets
No selected logo or reusable visual asset is required for this concept. Use the wordmark “Lumi” as currently rendered; do not invent a new mark.
